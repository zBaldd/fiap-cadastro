# App de Cadastro FIAP - Cadastro de Alunos (Firebase + Permissões)

Este projeto foi desenvolvido utilizando React Native (Expo Go) e Firebase (SDK Web)

Um app de Cadastro de alunos com funcionalidades de fotos e integrado diretamente com o Firebase

# Passo a passo

1.Clonar o projeto no VSCode;

2.Abrir o terminal e dar o comando npm install;

3.Abrir emulador no AndroidStudio;

4.npx expo start ou npm run android, para rodar o projeto no emulador.
